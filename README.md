# Инструменты автоматизированного сбора данных в сети Интернет

Лабораторные работы по курсу сбора и парсинга данных.

## Структура репозитория

### [Лабораторная работа 1 — Работа с REST API](./lab1/README.md)
* **Задание 1 (GitHub API):** Скрипт `github_repos.py` для автоматического получения списка репозиториев пользователя (`Meta1rus`) с постраничной пагинацией и сохранением в JSON.
* **Задание 2 (NASA Open APIs):** Скрипт `api_auth_request.py` для выполнения авторизованных запросов к сервисам APOD (астрономическая картинка дня) и NeoWs (околоземные астероиды) с сохранением ответов.

### [Лабораторная работа 2 — Сбор данных: BeautifulSoup и Octoparse](./lab2/README.md)
* **Часть A (BeautifulSoup):** Скрипт `scraper.py` для парсинга каталога интернет-магазина, очистки и типизации данных с помощью `pandas`, обработки сетевых ошибок (таймаут и повторные попытки) и выгрузки в CSV (`products.csv`).
* **Часть B (Octoparse):** No-code workflow для извлечения данных с постраничной пагинацией, экспорт данных (`octoparse_products.csv`), скриншоты процесса и сравнительный анализ программного и визуального подходов.
