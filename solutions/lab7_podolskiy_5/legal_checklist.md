# Правовой чек-лист (лабораторная 7, вариант 5)

| Пункт | Ответ |
|---|---|
| Источник(и) и их назначение | 1) `scrapingcourse.com/ecommerce` — учебная площадка ZenRows для тренировки сбора (источник варианта); 2) по согласованию — `scrapeme.live/shop` (учебный магазин того же автора, WooCommerce); 3) `httpbin.org` — сервис для тестирования HTTP-клиентов (воспроизведение кодов 429/503/401/403, ETag); 4) локальная имитация `tools/mock_shop.py` на 127.0.0.1 — собственный стенд для сценариев отказа. |
| Цель сбора и её правомерность | Учебная: отработка вежливого и устойчивого сбора (лабораторная курса ПГНИУ). Данные — синтетический каталог учебного магазина; коммерческого использования, перепродажи и публикации нет. |
| Проверка условий использования: есть ли запрет автоматического сбора | Площадки созданы для обучения сбору данных; явных условий, запрещающих автоматический сбор, на главной scrapingcourse.com нет (проверено 15.10.2026: текста об условиях использования на странице нет). Но **robots.txt scrapingcourse.com запрещает каталог** (см. ниже) — это выраженная воля владельца, и она соблюдается. Для scrapeme.live (проверено 16.10.2026): ссылок на условия использования, политику или запрет автоматического сбора на страницах `/` и `/shop/` нет; в подвале только «© ScrapeMe 2026»; robots.txt каталог разрешает. Сбор — по согласованию с преподавателем. |
| robots.txt: релевантные правила, Crawl-delay, результат can_fetch | scrapingcourse.com: `User-agent: *` / `Disallow: /ecommerce/*` → `can_fetch` = **False** для `/ecommerce/`, `/ecommerce/page/2/`, карточек (Protego и urllib.robotparser Python 3.13.16; в Python ≤ 3.12 и в 3.13.7 на Mac автора urllib ошибочно даёт True — поэтому решение по более строгому парсеру). Crawl-delay и Sitemap не указаны. Сбор на нём **не выполняется** (код 3). scrapeme.live: запрещены `/wp-admin/`, `/*?add-to-cart=`, служебные `wp-content/uploads/...`; `/shop/` разрешён; Sitemap `https://scrapeme.live/wp-sitemap.xml`; Crawl-delay нет; фактический результат (`reports/robots_report_scrapeme.live.json`, 16.10.2026): HTTP 200, `can_fetch` = True для `/shop/` и `/shop/page/2/` у обоих парсеров, Crawl-delay и Request-rate нет. httpbin.org (`reports/robots_report_httpbin.org.json`): HTTP 200, запрещён только `/deny`, Crawl-delay нет, `can_fetch` = True. |
| Используется ли доступ из-под авторизации | Нет. Cookies отключены; 401 обрабатывается как «нужна авторизация» без повторов. |
| Применяются ли средства обхода защиты | **Нет.** Нет прокси и ротации IP, нет подмены/ротации User-Agent, нет решения капчи, нет подделки отпечатков браузера. При вердикте «блокировка» сбор домена останавливается, скорость не повышается. |
| Объём и частота запросов, пиковая нагрузка на домен | Режимы B/C: ≤ 2 запр/с на домен (token bucket, всплеск 2), ≤ 2 одновременных соединения, джиттер 25 %, пауза после 429/503, Crawl-delay в приоритете. Прогон A (антипаттерн) — только на учебной площадке и ≤ 30 запросов. Объём одного прогона — 1–2 страницы каталога (≈ 18–35 запросов); всего за `run_real.sh` 16.10.2026 — ≈ 150 запросов к scrapeme.live (не больше 35 за прогон) и 48 к httpbin.org; повторная демонстрация возобновления после исправления — ещё 37 запросов к scrapeme.live. Пик на httpbin — единицы запросов в секунду. |
| Состав данных; есть ли персональные данные | Название, цена, артикул, категории, описание, изображение (URL) товара учебного магазина; служебные метаданные ответов (коды, размеры, заголовки ETag/Last-Modified). **Персональных данных нет** (152-ФЗ, ст. 3: данные, относящиеся к физическому лицу, не собираются). |
| Правовое основание обработки (при наличии ПДн) | Не требуется: ПДн отсутствуют. При их появлении (например, имена авторов отзывов) — не сохранять, фильтровать на уровне пайплайна. |
| Место и срок хранения, порядок удаления | Локально на рабочем компьютере: `data/crawl.db`, `logs/`, `reports/`, `state/`. Срок — до зачёта по курсу, затем удаление каталога лабораторной (артефакты инцидентов — тела ответов — удаляются вместе с `logs/incidents/`). В открытый доступ сырые данные не публикуются. |
| Контакт для связи, указанный в User-Agent | `PSU-edu-crawler/1.0 (+https://github.com/Meta1rus/web-data-extraction; student lab)` — ссылка на репозиторий курса с контактами. |
| Действия при получении претензии или блокировки | Немедленно остановить сбор (детектор делает это автоматически при «блокировке»), сохранить артефакты, связаться с владельцем, удалить собранные данные по запросу, не возобновлять сбор без разрешения; источник исключить из пайплайна и искать легальную альтернативу (API, открытый датасет, письменный запрос доступа). |
